# Wetransfer Alternative

This project is a white-label file sharing platform for small businesses.

Core product idea:
- Guests can send up to 2 GB and files expire after 24 hours
- Free registered users can send up to 10 GB and files expire after 72 hours
- Paid users can send up to 100 GB, keep files longer, and enable white-label branding

Initial planning docs:
- `docs/product-spec.md`
- `docs/database-schema.md`
- `docs/api-plan.md`

Recommended stack:
- Next.js
- PostgreSQL
- Prisma
- Cloudflare R2
- Stripe
